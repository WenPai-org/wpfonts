帮助

简要说明。

编辑器与排版

侧栏里的「文派字库」只改当前区块。已启用的文风字体包和已确认的文风云会进入全站样式，可在外观 → 样式 → 排版里选用。

中文

设置里可以指定正文、标题和中文回退。中文回退接在现有西文字体后面，主题里的字体类不用改代码。先启用文风字体包，或确认一条文风云。

系统字体

无需填写。字体库里的「系统 · 中文」「系统 · 英文」「系统 · 日文」「系统 · 韩文」仍然可用，前台不会因此请求远程字体。

文风云

默认关闭。开启并保存后，每条已确认的文风云字体各加一条样式链接。服务器只有 cn.windfonts.com、hk.windfonts.com 和 en.windfonts.com。网页中不会出现 API Key。

文风字体包

安装后文件放在本站。启用后可在全站样式里选用。

字体目录

目录保存在本站。大约每月自动更新一次，也可在设置里立刻更新。选中后写入字体名；更新失败不会盖掉已有目录。

全站样式

已启用的文风字体包和确认能打开的文风云会出现在全站样式里。不改主题文件。卸载时不删除全站样式。
